SmolLM2-135M is a small English drafting model, with limited accuracy. Use short facts you provide; independent factual answers are unreliable. Initial download: about 167 MB (160 MiB). No API key. Generation stays on this device. A suitable browser and at least 4 GB device memory are recommended; actual speed varies.

SmolLM2-135M یک مدل کوچک برای پیش‌نویس انگلیسی با دقت محدود است. برای پیش‌نویس از اطلاعاتی که خودت می‌دهی استفاده کن؛ پاسخ دانشی مستقل قابل‌اتکا نیست. دانلود اولیه حدود ۱۶۷ مگابایت است. کلید API لازم ندارد و تولید متن روی همین دستگاه انجام می‌شود. مرورگر مناسب و دست‌کم ۴ گیگابایت حافظهٔ دستگاه توصیه می‌شود؛ سرعت به دستگاه بستگی دارد.

Short contexts only: at most 768 input tokens including the fixed policy, and 64 output tokens. Large contexts are refused, never silently shortened. Downloaded model/runtime bytes can be cached; this does not save conversations.

Then choose “On-device small model” in the model settings. Prepare and approve the exact context before generating. Stop terminates the inference Worker; locking the archive unloads the model. Keep an encrypted backup separately.

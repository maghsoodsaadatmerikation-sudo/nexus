NEXUS / OFFLINE PILOT

Offline Decision Workshop

From a question to evidence, from evidence to alternatives, and from alternatives to your own judgment. This application never decides for you.

Language

Language switching changes interface text only and never sends workspace text for translation. English and Persian are built in; other languages require a complete local translation file. Optional browser voice services have separate consent.

English is the default language. Loaded language files apply only to this tab.

Custom translation; its accuracy has not been reviewed by NEXUS.

Internet research and search

Choose an engine and explicitly open search results in a separate browser tab. NEXUS does not crawl, scrape, merge or automatically summarize external results. The search provider receives your typed query when you confirm.

Custom templates use {searchTerms} exactly once as a URL query parameter. They stay in this tab; no API key is needed.

Provider results are not verified by NEXUS; the linked site has its own privacy policy, cookies and availability.

Nothing has been sent; internet actions are opt-in.

Manual source review

Only the browser opens third-party sites; NEXUS's offline app makes no background search API calls and does not transmit your workspace or passwords.

Internet access requires a connection, even when the NEXUS app was installed for offline use.

Search terms and links are not copied from your workspace automatically.

Files and document export

Files stay in memory in this tab; they are not uploaded to a server or included in encrypted workspace checkpoints. Add any file type, up to 10 MiB each, 20 MiB total and 20 files. Download a ZIP bundle to retain originals before closing or replacing this workspace.

Files in this page

Files are data, not verified evidence. A SHA-256 identifies bytes, not the truth of a file. Register any claim yourself after reviewing its source.

Text/source files and bounded DOCX, XLSX and PPTX text can be previewed. Layouts, images, embedded objects and formulas are not executed or interpreted. PDF, images, audio, video and other binary files remain downloadable originals; their content is not automatically understood.

Reports use committed workspace information only. Word and Excel are real DOCX/XLSX packages; PDF uses the browser print/save dialog. ZIP includes an unencrypted workspace JSON, report, file manifest and all current originals. Outputs are unencrypted and need a separate confirmation.

Files are ready. Nothing is sent automatically.

Safer export storage

    
Choose a long passphrase of at least 12 characters for the encrypted file. It is used only on this device when creating or opening the file and is not sent to a server or stored in the file. A forgotten passphrase cannot be recovered. Ordinary JSON exports are unencrypted.

    

      

      

      

    

    
Encryption: AES-256-GCM with a key derived through PBKDF2-SHA-256 and a random salt. This does not guarantee protection against weak passphrases, a compromised device, or loss of both file and passphrase. Keep the encrypted file somewhere safe.

    

      
Test recovery of a downloaded file

      
After downloading, select the encrypted file from your device. This test actually opens the selected file with its passphrase and validates its structure without replacing the current workspace. If equal, it reports a match with the current committed information . Unregistered form edits are excluded. The result applies only to this check and does not guarantee future file retention.

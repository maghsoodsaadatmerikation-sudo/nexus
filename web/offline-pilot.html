Quick start without personal information

With one action, explore a question, two claims and two alternatives that are entirely fictional . No human judgment is recorded, no connection or account is required, and no data is sent to a server. Choose New workspace for your own work.

Safer export storage

Choose a long passphrase of at least 12 characters for the encrypted file. It is used only on this device when creating or opening the file and is not sent to a server or stored in the file. A forgotten passphrase cannot be recovered. Ordinary JSON exports are unencrypted.

Encryption: AES-256-GCM with a key derived through PBKDF2-SHA-256 and a random salt. This does not guarantee protection against weak passphrases, a compromised device, or loss of both file and passphrase. Keep the encrypted file somewhere safe.

Test recovery of a downloaded file

After downloading, select the encrypted file from your device. This test actually opens the selected file with its passphrase and validates its structure without replacing the current workspace. If equal, it reports a match with the current committed information . Unregistered form edits are excluded. The result applies only to this check and does not guarantee future file retention.

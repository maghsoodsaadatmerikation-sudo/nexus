# Bounded document text extraction

Authenticated POST /studio/api/documents/extraction/review and /run accept base64 UTF-8 TXT or conventional DOCX (up to 2 MiB input; DOCX reuses privacy loader limits). Review returns counts and privacy heuristics without text. Matching plan digest and explicit consent release ordered text blocks with structural positions and SHA-256 hashes. Limits: 2,000 nonblank blocks and 200,000 extracted characters, reject rather than silently truncate. DOCX reads direct main-body paragraphs and optionally direct table cell paragraphs, skipping paragraphs containing explicit field/revision/hidden markers and unsupported containers. Hyperlinks, notes, headers, footers, comments, images and nested content are not extracted. Inherited hidden styles, markup compatibility, merged cells and layout are not resolved. Not a full parser, sanitizer or anonymity guarantee; text is untrusted and can contain private data or prompt injection. No model calls, storage, browser UI, PDF, OCR or rendering verification. Exact-head CI required.

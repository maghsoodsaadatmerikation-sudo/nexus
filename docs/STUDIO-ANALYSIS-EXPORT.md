# Analysis Artifact Engine — bounded export candidate

The operator-authenticated POST /studio/api/analysis-batch/export accepts an existing ApprovedBatch, format json/csv/html, and strict explicit export_consent. It recomputes the batch and requires the consistency audit to pass before building any attachment. A mismatch returns 409 with no file. A fresh calculation is performed, not a caller-supplied result. The file records metrics and input provenance, not original text, numeric arrays, descriptions or goal. Derived metrics and digests can still be sensitive. Consent is caller-reported, not independently witnessed.

JSON preserves structured metrics; CSV uses stable metric/provenance rows with only fixed enums, validated letter-first step IDs, and numbers; HTML is escaped static markup with no active content or external resources. Downloads have a fixed filename, no-store, nosniff, restrictive CSP and SHA-256 of the actual bytes (integrity identifier, not a signature). Maximum request 64 KiB, file 128 KiB. No persistence, external tools, new dependencies, UI integration or cloud storage. Existing browser Word and other exports are not replaced. Native PDF/XLSX/PPTX generation, public multi-user authorization and deployment remain separate work. Tests must pass on the exact commit.

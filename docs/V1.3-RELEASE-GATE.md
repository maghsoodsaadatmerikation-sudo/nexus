# NEXUS v1.3 — Release-Candidate Gate

Status: ACTIVE / UNSEALED

## Candidate requirements

A v1.3 release candidate is READY only when all of the following hold on one exact commit:

- G1 Historical seal integrity: PASS
- G2 Gateway authority non-expansion: PASS
- G3 Secret and evidence hygiene: PASS
- G4 Provenance and dependency integrity: PASS
- G5 Failure transparency: PASS
- G6 Operational economy: PASS
- full `NEXUS Verification` for the same commit completes successfully
- verification evidence is generated and uploaded without authentication material

The candidate manifest records the exact commit and the GitHub Actions run ID. Generation of a candidate manifest is not a release action.

## Human release authority

Tag creation and GitHub Release publication are separate from verification. Scheduled CI, evidence generation, and production-hardening gates have no release authority. Publication requires an explicit human release decision after the exact-candidate verification run has been independently confirmed successful.

## Constitutional boundary

`A_out <= A_in`

v1.3 hardens production operations. It does not claim formal proof of epistemic correctness, universal security, universal availability, or authority beyond explicitly authorized inputs.

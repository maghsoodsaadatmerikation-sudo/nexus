# Research uncertainty register

POST /studio/api/research/uncertainty-review requires operator authentication, original ConflictRequest and its exact conflict_review_sha256. It recomputes the existing conflict and graph reviews; upstream validation and the 256 KiB body cap apply. It projects claim-specific reasoning issues, missing/unclear source evidence, missing frames, unknown or differing scope dimensions and potential cross-claim conflicts into unresolved entries with deterministic IDs, categories, target node IDs, fixed review actions and counts. Shared-source interpretation differences remain separate. Every claim retains an independent-verification requirement. Unknown upstream issue codes are preserved with a generic review action.

Counts describe structural review items, not confidence, risk, evidence weight or truth. The list is not guaranteed complete, and a missing flag does not establish certainty. No probability, calibrated confidence, automated resolution, semantic inference, independent verification, persistence, external dispatch or UI integration is provided. Entry IDs identify a structural issue within its target namespace; the enclosing digest binds the exact input, so IDs alone are not reusable approvals. No raw source excerpts or claim prose are returned. Exact-head CI required.

# Creative workflow and text constraint review

The existing model gateway optionally accepts creative_profile with five media (literature, music, visual_design, film, problem_solving) and four tasks (draft, alternatives, critique, revise). Alternatives requests 2–5 different approaches. Fixed server guidance is appended to existing policy and response preferences; no free-form system input, automatic external action, provider change, extra call, or new credential. Existing consent, context, configuration and budget checks remain. Omission preserves the original behavior. These are text generation instructions, not verified model compliance or audio/image/video synthesis.

The operator-authenticated POST /studio/api/creative/review compares up to five supplied text drafts against explicit required/excluded literal substrings and a Unicode-code-point length cap. NFC+casefold matching, duplicate detection, exact text hashes and a reference review digest are deterministic. Returns indices of matched/missing rules rather than echoing raw text. No originality, quality, semantics, authorship or copyright check; substring checks can produce false positives for ordinary word fragments. No aesthetic score or winner. Existing offline Music Lab and Orchestra Lab are unchanged. No browser UI integration or live provider test; exact-head CI required.

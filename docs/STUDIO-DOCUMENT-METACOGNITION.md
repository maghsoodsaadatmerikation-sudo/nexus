# Document metacognitive review

Authenticated POST /studio/api/documents/metacognition recomputes the selected evidence and validates a nonempty cited draft. Accepts zero to three critique receipts; when supplied, validates HMAC, coverage, distinct slots, exact prepared provider payload and current route configuration, and checks compatible context. Produces deterministic unresolved review actions for lexical retrieval gaps, skipped content, omitted excerpts, model disagreement, reported opposition/insufficiency, unverified interpretation and unsupported assumptions of reviewer independence. Exact quotes remain candidates requiring contextual review; interpretations and disputed quotations are withheld pending review. No model call, automatic search, disclosure, correction or confidence estimation. Shared-token receipts are replayable and forgeable by token holders. Not introspection, independent semantic validation or an actual decision engine. No UI or deployment; exact-head CI required.

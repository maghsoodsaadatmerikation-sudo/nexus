# Academic plain-text anonymization review

Authenticated /studio/api/research/anonymization/review and /run process up to 16 uniquely named plain-text manuscript parts, each at most 12,000 characters, and 32 explicit literal rules. Caller chooses whole-part removals, names, affiliations, self-citation strings, funding or other identifiers. Email and ORCID syntax heuristics default on; NCT registration heuristic is opt-in. Review returns merged Unicode code-point ranges and categories, not matched strings, and binds the complete plan with SHA-256. Run requires matching digest and explicit consent, replaces merged spans with [REDACTED], omits selected parts, and rescans actual output for remaining rule matches. Rejects excessive matches rather than silently truncating. No regex supplied by caller, network requests, file metadata inspection, file modification, semantic identity inference, guaranteed anonymization, journal submission or UI. Output can still include sensitive text; no-store is not a guarantee against infrastructure logs. The digest is not a secret, and literal rules do not handle all Unicode variants, indirect identifiers or alternative citation spellings. Human verification against actual journal rules and original file metadata is required. Exact-head CI required.

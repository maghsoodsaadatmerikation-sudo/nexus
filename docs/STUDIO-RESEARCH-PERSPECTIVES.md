# Multi-perspective research review

Operator-authenticated POST /studio/api/research/perspective-review accepts the original UncertaintyRequest, matching uncertainty digest, and two to six caller-defined perspectives with unique IDs, labels and explicit claim memberships. It reruns upstream reviews; existing six-claim, 60-card and 256 KiB limits apply. Each perspective preserves claim-specific source links and unresolved issue IDs. Pairwise output separates shared and exclusive claims and source identities, and retains prior scope-aware comparisons between exclusive claims. Shared claims are not counted as cross-view conflicts. Unassigned claims are reported. Cross-view comparisons intentionally exclude pairs involving common claims, so the output is not a complete conflict inventory; upstream uncertainty remains applicable.

No automated creation of viewpoints, ideological inference, semantic interpretation, independent source validation, equal credibility assumption, ranking, synthesis, consensus verdict, persistence or UI wiring. Source counts are inventory counts, not evidential weight. The digest binds exact input, not truth. Labels and claim memberships are caller assertions, and all results require human review. Exact-head CI required.

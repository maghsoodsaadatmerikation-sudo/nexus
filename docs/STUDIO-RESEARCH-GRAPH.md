# Knowledge graph review

The operator-authenticated POST /studio/api/research/knowledge-graph accepts up to six named claim nodes, 24 caller-defined concepts and 60 total source cards, within 256 KiB. Each claim contains its original reasoning request and valid evidence digest. Existing reasoning and evidence validation are rerun. Concept links are explicit and must resolve. Matching source identities are consolidated across claims with deterministic IDs; source-to-claim edges retain the claim-specific caller stance, card indices, providers, kinds and method annotations. Shared identity never transfers stance, truth or authority across claims. The graph reports shared source IDs and claim-specific review issues. Concept labels are untrusted display text; claim prose and excerpts are not returned.

This is a bounded structural graph projection, not a persistent graph database, semantic extractor, causal model, contradiction detector across claims, or verified knowledge base. Shared sources need not establish independent evidence. No automated inference, retrieval, external dispatch, persistence, visualization or chat integration is introduced. The graph digest binds exact supplied input, not truth. All content remains unverified. Exact-head CI required.

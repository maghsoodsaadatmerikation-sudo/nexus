# Regression influence diagnostics

Authenticated /studio/api/statistics/diagnostics/review and /run extend the existing simple OLS model, for 4–1000 integer observations. Exact plan digest and explicit consent are required. Reports zero-based observation index, residual, leverage, internally studentized residual, Cook's distance, exact leave-one-out slope and slope change, with heuristic flags (h > 4/n, absolute studentized residual > 2, Cook's D > 4/n). Uses integer centered sums and rational expressions before division to avoid cancellation; handles constant predictor, zero residual variance and unit leverage without inventing undefined values. Does not echo original coordinates or remove observations. Tests compare against separately evaluated standard-library refits and formulas. This is influence screening, not verified outlier classification, bias detection, assumption testing, causal inference, external prediction validation or automatic correction. No new dependencies, UI, storage or provider calls. Exact-head CI required.

# Integrated research synthesis draft

Operator-authenticated POST /studio/api/research/synthesis accepts an original CritiqueRequest, matching reference draft digest and optional strict include_claim_text (default false). It recomputes the reviewed chain and rejects a structurally inconsistent candidate rather than silently repairing it. It builds one deterministic structured JSON report containing all claims, claim-specific source links and method annotations, numbered source identities shared across claims, canonical reference URLs, incomplete metadata flags, title conflicts across all occurrences, perspectives, unassigned/unframed claims, cross-claim comparisons and the full uncertainty register. Source excerpts and queries are not returned. Claim prose is included only when requested; labels, titles and optional claim text are untrusted display data. Report hash binds the exact canonical report, not a signature or scientific proof. Existing source and transport limits apply.

This is a structured evidence synthesis draft, not an automated systematic review, generated scientific narrative, meta-analysis, independent fact check or complete citation formatter. Source counts are not evidence weights; no clinical or causal conclusion is inferred. There are no external calls, persistence, file exports or browser integration. No new dependencies. Exact-head CI required.

# Shared multimodal review contract (image and text)

Vision now reads provider settings, opt-in and attempt cap from one environment snapshot, avoiding mixing an old destination with a rotated key. It uses the existing model gateway presentation profile and strict buffered response parser (one choice, assistant role, UTF-16 browser limit, no tool calls). Authenticated POST /studio-api/vision-plan accepts the image request without consent or request_review_id, validates the image structure and returns the image SHA-256, byte length, route, output limit, quota snapshot and keyed exact provider payload review ID. The optional ID on /studio-api/vision is checked before quota reservation and forwarding; changed prompt, image, profile, output allowance or credentials invalidate it. Preview sends image bytes to the NEXUS gateway, not the external provider, and does not reserve quota. It is not authorization or proof of human review and is replayable; each actual call still requires explicit consent. Older clients may omit it. The existing local browser preview is unchanged, and should remain the first privacy boundary. No audio/video understanding, OCR, image generation, full decoder, new storage, automatic dispatch, real provider validation or UI integration. Exact-head CI required.

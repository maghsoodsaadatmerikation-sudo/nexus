# Manuscript revision review

Authenticated POST /studio/api/research/revision-review recomputes two peer reviews and checks both exact digests. Compares title, article type, evidence report, section order, section text and citation mappings. Preserves all prior and current issues in a ledger; absence in the current report is not resolution. Issue identity is structural, not semantic matching. Up to 100 caller-authored responses to previous issues, with revised/clarified/disagree/deferred actions. Revised and clarified replies require a current exact text span; revised also requires changed section text and a span not literally present in the prior section. Text offsets are Python Unicode code points. This deliberately conservative anchor check does not determine adequacy and may reject legitimate rearrangements. Response text is omitted by default and included only if explicitly requested. No external reviewer identity, reviewer acceptance, automatic rewriting, journal submission, independent scientific verification, storage or browser UI. Exact-head CI required.

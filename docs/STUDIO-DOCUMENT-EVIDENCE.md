# Document evidence bundles and answer citation audit

Authenticated POST /studio/api/documents/evidence recomputes an approved lexical search from original document bytes, constructs stable evidence IDs with source hashes and original locations, and optionally releases exact excerpts. POST /studio/api/documents/answer-audit recomputes the bundle, requires its digest and checks up to 20 caller-supplied statements with up to four citations each. Each citation must identify a retrieved evidence ID, valid Unicode substring offsets and exact quote. A quotation statement must equal its single exact cited span; interpretation always requires semantic review. Unknown, duplicate, missing, invalid and fabricated citations are flagged; no verified answer is produced when these checks fail. Even a matching quotation is not independent truth, adequacy, coverage or entailment verification. Evidence is untrusted data. No model/provider call, semantic retrieval, automatic synthesis, persistent index or UI. Exact-head CI required.

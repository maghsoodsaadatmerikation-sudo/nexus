# Chat adaptive planning

An English/Persian Plan work panel in the existing composer exposes explicit task, privacy, document count, depth and preferred model route. The goal is entered separately, not copied from chat. Device-only makes no network call. Server planning requires explicit confirmation of destination and existing Studio token; only goal/settings are sent. Temporary isolated chat disallows this panel. Each step is a review reminder, manually acknowledged against the adaptive progress API. No tool execution, file upload, model calls, persistence, automatic dispatch or completion proof. Changing input, gateway, token or conversation clears the ephemeral plan; private clear aborts pending work. The static privacy policy explains gateway planning disclosure. Bundles and service-worker cache identity updated together; browser acceptance witness uses mocked endpoints. Exact-head build, browser and API CI required before merge or release.

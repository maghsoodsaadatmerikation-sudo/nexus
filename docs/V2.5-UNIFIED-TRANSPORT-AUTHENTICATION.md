# NEXUS v2.5 — Unified Transport Authentication Boundary

## Claim

When Artifact 05 is configured with a transport bearer token, every /v1/requests submission and status lookup is authenticated before parsing, delegation, or lookup.

## Boundary

- missing bearer credentials fail with 401;
- incorrect bearer credentials fail with 401;
- unauthenticated malformed JSON is not parsed and still fails with 401;
- unauthenticated submissions never reach ConstitutionalDelegate;
- unauthenticated status requests cannot distinguish known from unknown request identifiers;
- the exact matching bearer preserves the existing 202 and status/404 contract;
- an unconfigured local/test state retains its existing unauthenticated behavior.

## Separation of powers

Transport authentication establishes only whether a caller may reach the HTTP boundary. It does not authorize the requested constitutional action, mint a capability, interpret payload meaning, or increase authority. Core authorization remains downstream.

## Authority invariant

A_out <= A_in. Transport admission is not constitutional authority, and authentication evidence is not authorization.

## Non-claims

This boundary does not claim credential rotation, cryptographic channel authenticity beyond the deployment's TLS boundary, external identity federation, rate limiting, distributed session state, durable persistence, consensus, universal security, or external-system linearizability.

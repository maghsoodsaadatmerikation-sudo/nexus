# Paired statistical analysis (v1)

Authenticated /studio/api/statistics/paired/review and /run support 2–1000 caller-supplied paired integer observations, each within ±10^12, with fixed after-minus-before direction. The reviewed SHA-256 binds the exact plan, assumptions and confidence setting; run requires matching digest and explicit consent. Calculates descriptive mean, median, sample SD, range and sign counts. If valid pairing and independent pairs are explicitly reported, calculates the exact two-sided binomial sign-test p-value conditional on nonzero differences and a 90/95/99% approximate Wilson interval for the positive fraction among those differences. All ties or missing assumption assertions return no inferential result. Does not independently validate independence, study design, clinical significance, causality, sampling, missingness or multiplicity. No automatic test selection, decimal input, t-tests, regression, effect-size standardization, model calls, persistence or Studio UI integration. Standard library only. Exact-head CI required.

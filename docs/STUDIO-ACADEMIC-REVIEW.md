# Academic manuscript structural review

Authenticated POST /studio/api/research/manuscript-review reviews caller-authored text, not generated findings. Select empirical, conceptual or commentary structure; supply title, up to eight named sections and explicit claim-to-reference mappings from an exact recomputed synthesis report. Optional word ceilings use whitespace tokens (not journal-specific word counters), with default title 40, abstract 250, section total 6000. The section total includes declarations and abstract but excludes title and bibliography. Required sections are generic templates, not verified journal policy. Missing sections, unmapped reviewed claims, missing citations, metadata-only citations, omitted opposing/mixed links and exceeded limits are findings. Unassociated references, duplicate IDs and stale synthesis are rejected. All research uncertainties and incomplete reference metadata remain available. The digest binds original input and text; it does not certify scientific merit. No raw manuscript prose is echoed, stored, sent to providers or submitted by this endpoint.

Explicit mappings do not verify that prose contains the mapped claim, that every prose claim is mapped, or that citations entail claims. No authorship, plagiarism, ethics, anonymity, reporting guideline, journal instructions, publication readiness or independent evidence check. No automated article writing, upload, external calls, UI or file export in this step. Exact-head CI required.

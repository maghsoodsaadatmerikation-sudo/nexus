# Research citation drafts

The operator-authenticated POST /studio/api/research/citations accepts the original EvidenceRequest, its matching review_sha256 and explicit selected source indices. It recomputes evidence review before building references, groups matching DOI/page identities, uses inventory order for numbered IDs and records both selected and related source indices. Conflicting titles among selected records are surfaced rather than silently resolved. No original excerpt or claim is included.

Outputs include numbered plain-text reference drafts, structured traceable entries and minimal CSL-JSON-shaped records suitable for downstream enrichment. The record type is generic (article or webpage), not a verified publication type. Author, publication date and journal/container are never extracted heuristically or invented. Missing metadata is explicit, and all entries remain incomplete and unverified. This is not full APA/Vancouver/BibTeX formatting, independent bibliographic verification, citation entailment, or a guarantee that a source exists. No network, external execution, persistence, or browser integration is added. The existing evidence review remains unchanged. Exact-head CI is required.

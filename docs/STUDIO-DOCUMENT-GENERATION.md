# Grounded document generation (v1)

Authenticated /studio/api/documents/generation/review and /run recompute the evidence bundle and bind an explicit selection of 1–8 excerpts, question, configured model slot and token limit to the existing keyed exact provider-payload review. Review shows exact selected excerpts and destination model/host and makes no call. Run requires boolean provider consent and matching review ID. Uses the existing model limiter, attempt budget, frozen route and adapter contracts; one buffered attempt, no retry/fallback or tools. Only selected excerpts/IDs, evidence digest and question are included in document context, not full files or unselected hits. Strict JSON output with 1–8 quotation/interpretation statements and 1–4 exact unique substring citations each, or explicit abstention. Rejects unknown, ambiguous, duplicated or nonmatching citations, malformed/truncated replies and extra fields without returning raw output. Citation positions are derived server-side; interpretations always unverified. No semantic entailment, truth, provider retention, cost or independent verification; prompt injection is not eliminated by instructions or citation checks. No browser integration, live provider test or deployment in this change. Offline mocked provider tests; exact-head CI required.

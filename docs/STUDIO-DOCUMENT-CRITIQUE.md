# Model-assisted document critique

Authenticated /studio/api/documents/critique/review and /run validate a caller-supplied cited draft against the selected original evidence. Explicitly reviewed question, draft, excerpts, configured route and output budget are bound to the exact provider payload. Separate provider consent is required. Reuses the existing buffered dispatch limiter, attempt budget and response bounds; one call, no fallback. Reviewer model must cover each statement exactly once with a reported supported/contradicted/mixed/insufficient verdict and rationale. Non-abstaining verdicts require exact citations, checked with the same source validator. All verdicts remain unverified. A conservative candidate retains only original exact quotations reported supported; interpretations and disputed quotations are withheld, with indices and critique preserved. This is filtering, not rewriting, independent semantic verification or automatic truth determination. Caller draft is not authenticated as model output. No external reviewer certification, live provider test, UI or deployment. Exact-head CI required.

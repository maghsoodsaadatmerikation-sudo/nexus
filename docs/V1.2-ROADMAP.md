# NEXUS v1.2 Roadmap — Operational Resilience

Status: DEVELOPMENT / UNSEALED

NEXUS v1.1.0 remains the immutable durable-host release boundary. v1.2 development must not rewrite or weaken that historical evidence.

## Constitutional invariant

`A_out <= A_in`

Operational automation may observe, verify, preserve evidence, and report failures. It must not silently expand epistemic or execution authority.

## Goal

Turn the v1.1 durable deployment proof into a maintainable operational posture without introducing paid infrastructure as a requirement.

## Gates

### G1 — Release-boundary integrity
- Verify the v1.1.0 tag/release boundary remains fixed.
- Verify referenced evidence identifiers and hashes remain internally consistent.
- Fail closed on drift or missing evidence.

### G2 — Continuous verification
- Keep deterministic CI verification on source changes.
- Keep scheduled Artifact 05 verification at 00:00, 08:00, and 16:00 UTC.
- Scheduled checks may report evidence; they do not authorize a release.

### G3 — Durable-state resilience
- Preserve `/data` as the runtime persistence boundary.
- Define an operator-controlled, secret-free backup/export procedure.
- Validate restore with a dedicated witness only; never destructively test user data.

### G4 — Operational economy
- Auxiliary evidence/operator services must not remain running after evidence capture.
- No paid resource upgrade is part of this roadmap.
- If the hosting provider requires billing beyond currently available included resources, progression stops rather than silently incurring cost.

### G5 — v1.2 release gate
- Exact candidate commit must have successful NEXUS Verification.
- Operational-resilience evidence must be reproducible and secret-free.
- A release candidate may be marked READY only after all v1.2 gates pass.
- Tag/release creation remains an explicit human release decision.

## Current state

v1.2 is now defined but not complete, verified, or sealed. The first implementation target is G1: a fail-closed release-boundary integrity check for v1.1.0.

# Journal policy comparison

Authenticated POST /studio/api/research/journal-review compares an exact reviewed manuscript with up to 12 caller-supplied journal policy snapshots. Checks reported article types, word limits (whitespace tokens; main text excludes abstract, declarations, title and bibliography), required sections, literal topic tags, reported mandatory publication fees against an explicit same-currency budget, and flags anonymization for manual review. Amounts use caller-supplied currency codes and minor units, not a currency conversion or validation service. Unknown policy fields remain unknown; zero reported fee is not a verified fee-free publication route. Each policy has a caller-supplied date and HTTPS URL; neither is authenticated or fetched. No ranking, semantic scope matching, journal discovery, current instructions lookup, impact metrics, indexing checks, waiver inference, predatory-journal classification, verified compliance, submission, storage or UI. Existing scientific issues remain visible. The review digest binds all inputs. Exact-head CI required.

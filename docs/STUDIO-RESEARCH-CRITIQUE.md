# Research draft critique

Operator-authenticated POST /studio/api/research/draft-critique requires the original PerspectiveRequest and matching perspective review digest. Omitting candidate generates a structured reference draft covering every claim, claim-specific source relation/metadata flag, explicit perspective membership and every upstream unresolved item, including unassigned claims. Supplying a candidate checks missing, extra, duplicate or altered links, unsupported verification status, omitted perspectives or uncertainties and attempted authority escalation. Results distinguish reference_draft, revision_required and structurally_consistent. The first 100 findings are returned with the total and truncation flag. Expected structured reference data is returned for correction. The reference digest binds the exact perspective input and expected draft.

This is deterministic structural critique, not independent semantic reasoning, prose review, citation entailment, factual verification, model self-awareness or an autonomous revision loop. A consistent draft can still reflect incorrect input annotations. No free-form conclusion, confidence scores, automatic truth or authority elevation. No external requests, storage, new dependencies or chat integration. Request cap 384 KiB, with nested perspective JSON capped at 256 KiB; upstream cardinality bounds remain. All results require human review. Exact-head CI required.

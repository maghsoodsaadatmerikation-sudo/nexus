# Bounded sensitivity analysis

Authenticated /studio/api/statistics/sensitivity/review and /run support explicit leave_one_out (3–100 studies, one exclusion at a time, reusing both existing pooling methods) and prior_sensitivity (1–8 distinct non-baseline integer Beta priors, fixed observations and likelihood). Exact plan digest and explicit consent bind all scenarios. The baseline and every scenario are recomputed using the existing engines, including assumption gates. Results preserve model-specific intervals, heterogeneity or posterior probabilities, changes versus baseline, and min/max across baseline plus scenarios. These ranges are descriptive, not uncertainty intervals. No scenario selection, automatic robustness verdict, bias correction, independent verification, causal interpretation, provider calls, storage or UI integration. Existing engine limitations continue to apply. Exact-head CI required.

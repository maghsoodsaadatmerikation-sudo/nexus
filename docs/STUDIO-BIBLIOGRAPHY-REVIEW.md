# Bibliographic metadata reconciliation

Authenticated POST /studio/api/research/bibliography-review binds explicitly supplied metadata to a freshly recomputed synthesis report and exact reference number/source ID. Accepts up to 120 records with one caller-reported origin per reference per origin label. Preserves field observations and flags conflicts rather than picking a winning provider. Missing fields remain absent; author initials are explicitly provided in a restricted Latin-initial format. Canonical source URL and DOI come only from the existing source identity. Partial CSL-like metadata has no inferred publication type. For DOI references with all required journal-layout fields and no conflicting observations, generates plain-text APA-like and Vancouver-like journal layouts. These are drafts, not validated style-engine results; capitalization, typography, full author conventions, journal abbreviations, article type, dates and electronic locators require manual review. DOI does not prove article type. Origin labels are caller assertions, not provider attestations. No retrieval, network call, automatic publication, independent verification, new dependency, storage or UI integration. No invented missing authors, years, journal titles or volume information. Exact-head CI required.

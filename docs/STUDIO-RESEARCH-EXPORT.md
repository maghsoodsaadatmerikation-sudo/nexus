# Research synthesis exports

Authenticated POST /studio/api/research/export accepts the original SynthesisRequest, its exact report_sha256, format json or html, and explicit boolean export_consent. It recomputes the full synthesis and rejects stale digests or structurally damaged drafts. JSON preserves the full reviewed report. Standalone HTML renders limitations, claim-specific evidence links, perspectives, scope differences, unresolved uncertainties and incomplete references, with the complete structured report in a native details element. All untrusted fields are escaped; source URLs are displayed as inert text. The file contains no external resources, script or executable action. It includes the report digest; the HTTP response separately hashes exact downloaded bytes. Claim prose remains off unless opted in during synthesis and therefore bound to the reviewed digest. Output is capped at 512 KiB, input at 384 KiB. No server persistence, external model calls, independent verification, scientific narrative generation, submission, DOCX/PDF export or UI wiring. Counts and structural consistency are not scientific validity. Tests exercise deterministic output, provenance retention, HTML escaping, explicit consent and transport bounds. Exact-head CI required.

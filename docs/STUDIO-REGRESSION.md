# Simple regression and correlation

Authenticated /studio/api/statistics/regression/review and /run use 3–1000 integer (x,y) observations within ±10^12, a fixed ordinary least squares model with intercept, a review digest and explicit consent. Returns Pearson correlation, Spearman correlation with averaged ties, slope, intercept, centered means, R², standardized slope, residual sum of squares, in-sample RMSE and residual standard error. Centered sums and SSE numerator use exact integer arithmetic before final floating-point division, avoiding raw-moment cancellation at large offsets. Undefined correlations and R² are null for constant variables; constant predictor yields no unique fit. Diagnostics mark perfect in-sample fit and ties. No automatic test choice, confidence intervals, p-values, multivariable regression, decimal inputs, assumption verification, causal inference, independent prediction validation, network, persistence or browser UI. Standard library only; tests compare with Python statistics and exact fixtures. Exact-head CI required.

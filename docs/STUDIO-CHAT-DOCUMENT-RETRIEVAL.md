# Chat document retrieval panel

Ask documents is an explicit chat-adjacent panel for 1–3 TXT/DOCX files (2 MiB total, combined base64 cap). It requires a configured Studio gateway and token, and confirms the destination before each whole-file upload. Review returns counts and privacy/omission indicators; a second confirmation retrieves source excerpts with local filename, block index and Unicode offsets. No filenames, chat history, external provider call, automatic attachment, model generation or persistence. Input or gateway changes invalidate the review; project/thread changes and private clear abort and discard state. Isolated chats cannot open the panel. Results are rendered as text, bounded to 256 KiB transport; only lexical retrieval, not semantic answers. Bundled standalone and public shell updated with deterministic worker hashes. Browser acceptance uses a mocked gateway; deployment and live gateway verification are separate.

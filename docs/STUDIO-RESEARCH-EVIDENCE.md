# Studio evidence inventory review

POST /studio/api/research/evidence-review accepts an explicit claim, up to 60 existing Studio research-card objects (including optional queries), and optional caller-provided stance labels. The 256 KiB request cap also applies. Source identity is validated against the existing Wikipedia, Crossref and Europe PMC card URL shapes. Case-insensitive decoded DOI identities consolidate repeated records, without counting provider duplication as independent evidence. Wikipedia language/page and Europe PMC record identifiers are grouped separately; cross-identifier equivalence is not inferred.

Metadata-only cards cannot be marked supporting or challenging. Stance labels are caller-supplied, not model inference or verified findings. Mixed labels for one identity are reported separately; opposing labels across identities indicate reported disagreement only. The digest binds the input, not truth or signed approval. No excerpts, query text or claim prose are reflected in the inventory. No automatic source retrieval, network, source authentication, peer-review scoring, causal inference, clinical recommendation, persistence or UI wiring is introduced. The operator must explicitly submit cards to the gateway; existing direct browser searches are unchanged. The endpoint is operator-authenticated and no-store. Exact-head CI and integration review required.

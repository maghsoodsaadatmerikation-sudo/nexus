# Pilot 13 — readable local decision report

The offline workshop now produces a Persian readable report of **committed**
question, goal, constraints, values, claims with provenance/uncertainty/source,
alternatives with consequences, and the explicitly recorded human judgment.
An absent judgment stays absent. The report lists missing structural fields;
it never scores evidence, recommends an option or supplies a decision.

Choose **نمایش گزارش ثبت‌شده** after recording a question. Unsubmitted form
text and every password field are excluded. The report uses textContent only;
imported markup and source strings never become executable HTML or links.
Changing committed data, importing a workspace or starting a new one clears
the report and disables download/print until the user rebuilds it.
**بستن گزارش** clears only the preview, without changing the workspace.

A text download and browser print/PDF dialog require separate explicit
confirmation because both outputs are plaintext. Print CSS excludes forms,
passwords, installation controls and unrelated panels. The report is a readable
record, not an importable recovery archive; keep the separate encrypted JSON.
No network, account, new local storage, machine authority or schema migration
is added. Browser print/PDF availability depends on the device.

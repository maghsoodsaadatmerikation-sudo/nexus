# Beta-Bernoulli analysis (v1)

Authenticated /studio/api/statistics/bayesian/review and /run accept 1–1000 binary observations as success/failure counts and an explicit integer-shape Beta prior (alpha/beta each 1–100). The review digest binds the exact inputs, threshold, credibility level and assumption assertions. Matching digest and explicit consent are required. If independent trials and a common fixed probability are reported, calculates conjugate posterior parameters, mean, variance, 90/95/99% equal-tailed credible interval, posterior probability above a user-set threshold (increments of 0.001), and predictive probability for one new trial under this model. Otherwise only descriptive counts/fraction are returned. Integer-shape beta CDF uses the binomial-tail identity in log space and bounded bisection; interval and tail results are numerical approximations and extreme tails can underflow. Standard library only. No assumption verification, prior elicitation or sensitivity automation, MCMC, regression, Bayes factors, causal inference, decision recommendations, clinical prediction, persistence, external calls or browser integration. Exact-head CI required.

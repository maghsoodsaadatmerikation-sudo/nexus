# Analysis consistency audit

POST /studio/api/analysis-batch/audit is operator-authenticated and accepts the original approved batch plus a candidate result. It independently recomputes numerical summaries using statistics.mean/median and min/max, resolves references from recomputed values, and checks the complete expected output envelope, order, metrics and provenance. Text counts reuse Python's Unicode primitives. Changed input, false consent or invalid references fail closed. Discrepancies produce a bounded list of structured findings and an explicitly separate recomputed result; the original candidate is not mutated or stored. Finding paths contain only expected field names and bounded array indices. No input prose or extra candidate field names are reflected in findings.

The audit is computational consistency checking, not an independent security signature, human approval, external source verification, or general language-model critique. The verifier shares the same input schema, dependency planner and some primitives with the main engine, so common-mode errors remain possible. A caller can compute a matching digest; operator authentication is still required. No external execution is authorized. No new dependency, persistent data, network or UI is introduced. Requests are limited to 96 KiB and findings to 32 entries; large approved batches with candidates may exceed the audit request cap. Exact-head tests and deployment review remain required.

# Bounded document search

Authenticated /studio/api/documents/search/review and /run search 1–3 distinct TXT/DOCX documents, reusing exact extraction review digests and recomputing extraction from original bytes. Combined base64 budget 2,796,204 characters, extracted text 300,000 characters. Query 1–16 distinct Unicode word tokens; NFKC/casefold and selected Persian/Arabic variants. Any/all matching within overlapping 800-character original-text windows, deterministic ordering by distinct matched token count then input document/block order; up to 20 hits, one per block. Review omits text; run requires exact digest and explicit consent. Each excerpt includes original block location, offsets, document/block/excerpt hashes and untrusted-content label. No embeddings, semantic relevance, answer generation, persistent index, complete extraction or independent verification. No external calls or browser UI. No lexical match is not proof of absence. Exact-head CI required.
